# XMA 开发计划

## 0.1.x：平台出生期

目标：让 XMA 成为真正可运行的多 Provider Agent Harness，而不是目录骨架。

主要任务：

- Core Agent Loop；
- Provider profiles + real probe；
- Plugin Host + DeepSeek Harness Compatibility Layer；
- Workspace isolation；
- Tool Registry + Approval；
- Rust Native Runtime；
- CLI TUI；
- Minecraft Agent 第一条真实垂直链。

## 0.2.x：专业 Agent 扩展期

进入 0.2.0 的前提：0.1.100 完成阶段验收。

计划：

- Minecraft Agent 产品化；
- Xiaoyu Code 第一条 Coding Agent 闭环；
- Plugin/Skill 安装机制；
- Desktop 工作区管理；
- 更完整 DSH 插件服务兼容。

## 后续

Writer、Research、DevOps 等 Agent 必须在 Core/Workspace/Plugin 边界稳定后逐步加入，禁止为了展示功能数量制造空壳。
