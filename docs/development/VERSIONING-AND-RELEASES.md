# XMA 版本与发布规范

## 版本格式

使用 `major.minor.patch`，但 XMA 约定每 100 个 patch 进入下一个 minor 阶段：

```text
0.1.0
0.1.1
...
0.1.99
0.1.100
0.2.0
```

`0.1.100` 是 0.1 阶段的收官版本；下一阶段从 `0.2.0` 开始。

## 包命名

固定：

```text
xma-0.1.0.zip
xma-0.1.0.sha256.txt
```

禁止 `hotfix / final / fixed / v2 / new` 等临时后缀。

## 未冻结修正

如果某个版本还没有正式冻结，修复后仍然重新生成同名版本包，以最新 SHA-256 为准。
