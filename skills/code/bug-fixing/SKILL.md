# Bug Fixing

## 目标

找到缺陷根因，实施尽量小且可维护的修复，并避免无关改动。

## 工作方法

1. 先读取项目规则和与问题直接相关的代码，不要凭文件名猜实现。
2. 尽可能复现问题或确认失败条件，再修改代码。
3. 区分症状和根因；优先修根因，不用临时绕过掩盖错误。
4. 修改范围保持最小，不顺手重构与当前任务无关的模块。
5. 涉及安全、权限、持久化或兼容性时，补对应回归测试。
6. 修改后检查相关文件和 Diff，确认没有意外副作用。
7. 能执行验证时继续运行测试/检查；不能执行时明确说明原因。

## 交付

最终说明至少包含根因、修改点、验证证据和剩余风险。
